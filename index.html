Como publicar

  1. Crie um repositório no GitHub.
  2. Envie este index.html.
  3. Envie seu modelo com o nome modelo.glb.
  4. Ative GitHub Pages em Settings → Pages.
  5. Abra o endereço do site pelo celular e toque em Ativar experiência.
